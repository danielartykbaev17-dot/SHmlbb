SHmlbb — веб-платформа MVP

Запуск Windows:
1) Установи Python 3.11+ с python.org (галочка Add Python to PATH).
2) Распакуй архив и открой папку SHmlbb_web.
3) В адресной строке Проводника введи cmd и нажми Enter.
4) Выполни: py -m pip install -r requirements.txt
5) Выполни: py app.py
6) Открой: http://127.0.0.1:5000

Есть регистрация/вход, профили, поиск игроков, команды, заявки и таблица рангов. Игроки со всех серверов могут регистрироваться.
Это локальная версия для разработки, пока доступная только на твоём компьютере. Для публикации в интернете нужны хостинг, домен, HTTPS, production-сервер, надёжный SECRET_KEY и отключённый debug. Статистика игры пока заполняется вручную; официальный API не подключён. Не вводи пароль от игрового аккаунта — используй отдельный пароль SHmlbb.


НАГРАДЫ И АДМИНИСТРИРОВАНИЕ:
- В меню есть раздел /awards с победителями по пяти ролям, MVP, лучшим игроком и командой сезона и за всю историю.
- Награды пока назначаются вручную администратором, так как официальная игровая статистика не подключена.
- Чтобы назначить администратора, сначала зарегистрируй аккаунт на сайте, узнай его числовой ID в SQLite таблице users (поле id), затем задай переменную окружения ADMIN_IDS равной этому ID. Для нескольких администраторов укажи ID через запятую.
- После перезапуска сайта администратор войдёт в /admin/awards, создаст сезон, затем добавит победителей.

НАГРАДЫ И СЕЗОНЫ: страница /awards показывает лучших игроков по каждой роли, игрока сезона, лучшего игрока всех сезонов, лучшую команду сезона и лучшую команду всех сезонов. Для внесения результатов задайте переменную окружения SHMLBB_ADMIN_KEY (секретный ключ), откройте /admin/awards и войдите. Создайте сезон, затем добавляйте статистику игроков (MVP, победы, матчи, роль) и команд (победы, матчи, очки). Результаты рассчитываются по введённым данным. Автоматическая проверка матчей и официальный MLBB API пока не подключены.
